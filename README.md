# AI Behavioural Authentication
BhAuth, as I call it is a behavioural authentication using machine learning, based on keystroke dynamics and mouse movement pattern.

## Supervisor: Vivek Singh

# Project Vision
For secured systems whose aim is to tackle unauthorized access due to improper password management either from the user side or through a data breach, there is a need for proper authentication system which has more features than the traditional username-password method, or even two factor authentication as this tends to be easily bypassed if not implemented correctly. 
BhAuth as I call it, is an authentication system that authenticates users not only by username and password, but also by user keystroke dynamics and mouse movement patterns, ensuring first-hand integrity of the user as users’ behaviours are unique and cannot be imitated by an intruder. 
This system is different from traditional username-password authentication in such a way that it does not only validate the username and password, it also validates the user’s keystrokes when filling the login form, and also the mouse movement patterns to spot any difference in behaviour and to verify the integrity of the user. 
This could eliminate the need for multi factor authentication through one-time codes or email verifications. As the user behaviour is unique, this would uniquely certify the integrity of a user before granting access.
The project could also extend, if time permits, to cover real time authentication of user behaviour throughout the user session. Continuous authentication helps validate that the user remains the user throughout the session, ensuring first-class integrity of users in a secured system.

This project will employ the benefits of machine learning to learn and recognise user keystroke and mouse behaviours, helping spot an unauthorised user even when the username and password appears to be correct.
